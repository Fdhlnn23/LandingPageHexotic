Cara Bermain

Ikuti langkah sederhana ini untuk bergabung ke dalam kota.

1

Join Discord

Masuk ke server Discord kami untuk membaca peraturan dasar dan info server.

2

Daftar UCP

Gunakan bot di channel registrasi untuk membuat akun User Control Panel (UCP).

3

Connect IP

Tambahkan IP server di client SA-MP kamu dan gunakan nama UCP untuk login.

4

Buat Karakter

Masukkan PIN dari bot, lalu buat karakter pertamamu dengan nama RP (First_Last).
